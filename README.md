# Phân Tích Cảm Xúc Đa Ngôn Ngữ với FastAPI và Hugging Face

## 1. Thông tin sinh viên

- **Họ và tên:** [Nguyễn Hữu Khánh]
- **MSSV:** [24120340]
- **Môn học:** Tư duy tính toán (ĐH KHTN ĐHQG-HCM)
- **Bài thực hành:** Bài số 1 - Application Programming Interface

## 2. Thông tin Mô hình

- **Tên mô hình:** `tabularisai/multilingual-sentiment-analysis`
- **Liên kết Hugging Face:** [https://huggingface.co/tabularisai/multilingual-sentiment-analysis](https://huggingface.co/tabularisai/multilingual-sentiment-analysis)
- **Mô tả chức năng:** Hệ thống API nhận đầu vào là một chuỗi văn bản (hỗ trợ nhiều ngôn ngữ như Tiếng Anh, Tiếng Việt,...) và trả về nhãn cảm xúc của văn bản đó (ví dụ: Tích cực, Tiêu cực) kèm theo độ tự tin (confidence score) của mô hình.

## 3. Hướng dẫn cài đặt thư viện

Yêu cầu hệ thống đã cài đặt Python 3.8 trở lên.
Tạo môi trường ảo (tùy chọn) và chạy lệnh sau để cài đặt các thư viện cần thiết:

```bash
pip install -r requirements.txt
```
